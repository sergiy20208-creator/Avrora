# Avrora

Відеоредактор із локальним розпізнаванням мовлення Whisper на Python 3.12.
Сервер: FastAPI + SQLite. Інтерфейс: HTML/CSS/JavaScript.

## Запуск у Windows (PowerShell)

Виконайте в каталозі проєкту з Python 3.12:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

Якщо `.env` уже існує, пропустіть копіювання.
Відкрийте http://127.0.0.1:8000. API: http://127.0.0.1:8000/docs.
Зупинка: Ctrl+C. Наступний запуск: `powershell -ExecutionPolicy Bypass -File .\start.ps1`.
База `video_editor.db` і каталоги `storage/` створюються автоматично.

## Як отримати субтитри

1. Натисніть «Новий проєкт» і завантажте відео з аудіодоріжкою.
2. Виберіть мову або залиште автоматичне визначення. У блоці «Оформлення субтитрів» виберіть шрифт і насиченість; зразок покаже результат ще до розпізнавання. Додатковий перегляд доступний у «Бібліотеці шрифтів».
3. Натисніть «Розпізнати мовлення» й дочекайтеся завершення.
4. Субтитри відображаються на відео; натискання на фрагмент тексту перемотує плеєр.
5. Натисніть «Завантажити SRT», щоб зберегти файл субтитрів.

Шрифт можна змінювати й після розпізнавання; вибір зберігається в цьому браузері.
Для завантаження шрифтів потрібен інтернет; без нього використовується резервний системний шрифт.
Оформлення застосовується до перегляду відео, а SRT містить лише текст і часові мітки.

Результат зберігається у `storage/projects/<id>/transcript.json` і залишається після
перезапуску. Повторне розпізнавання замінює попередній результат. Після аварійної
зупинки незавершене завдання можна запустити ще раз.

## Whisper і Python 3.12

Використовується [faster-whisper](https://github.com/SYSTRAN/faster-whisper), локальна
реалізація Whisper. Аудіо декодується через PyAV із вбудованими бібліотеками FFmpeg;
окремий FFmpeg, PyTorch, CUDA та API-ключ не потрібні для стандартного запуску на CPU.
Медіафайли не відправляються до сервісу розпізнавання.

Налаштування `.env` (зміни набувають чинності після перезапуску сервера):

```dotenv
WHISPER_MODEL_SIZE=base
WHISPER_DEVICE=
WHISPER_COMPUTE_TYPE=
WHISPER_MODEL_DIR=./storage/models
```

Перший запуск завантажує модель із Hugging Face у `storage/models`. Для вже
завантаженої моделі розпізнавання працює локально. `base` — стандартний варіант;
для перевірки якості на ваших українських записах можна спробувати `small`
(потрібні окреме завантаження та більше ресурсів). Якщо CUDA доступна, backend
автоматично використовує `cuda` та `float16`; інакше — `cpu` та `int8`.
Моделі з суфіксом `.en` призначені лише для англійської. Розпізнавання не перекладає текст.

У залежностях зафіксовано NumPy 1.26.4: перевірено в цьому середовищі Windows/Python 3.12;
автоматично встановлений NumPy 2.5.2 тут спричиняв помилку завантаження DLL.
Запускайте один процес Uvicorn, без `--workers`: одночасно обробляється одне відео.
Прогрес підготовки моделі невизначений; відсотки під час розпізнавання орієнтовні.

## API

- `POST /api/projects/{id}/transcription` — JSON `{"language":"uk"}` або `{"language":"auto"}`; повертає 202, обробка у фоні.
- `GET /api/projects/{id}/transcription` — стан `idle`, `processing`, `completed`, `failed`, прогрес і результат.
- `GET /api/projects/{id}/subtitles.srt` — файл SRT після завершення.

## Стан реалізації

Працюють проєкти, перегляд відео, локальна транскрипція, субтитри та експорт SRT.
Тривалість у списку оновлюється після транскрипції. Відтворення залежить від підтримки
відеокодека браузером; для перевірки підходить MP4 з H.264/AAC.
Монтаж, Reels, видалення тиші та експорт відео з вбудованими субтитрами ще не реалізовані.

## Перевірка

```powershell
.\.venv\Scripts\python.exe verify_app.py
.\.venv\Scripts\python.exe test_transcription.py
```

Ці перевірки використовують тимчасову базу. Тести API підміняють розпізнавач,
тому не завантажують модель. Реальну обробку MP4 можна перевірити на WAV із мовленням:

```powershell
.\.venv\Scripts\python.exe verify_whisper.py path\to\speech.wav
```

Перевірка інтерфейсу в Microsoft Edge із тестовим розпізнавачем:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe verify_browser.py path\to\speech.wav
```

Тестові WAV мають містити щонайменше 5 секунд англійського мовлення.
